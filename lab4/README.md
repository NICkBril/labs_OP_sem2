# Lab 4 – Bi-Directional Priority Queue

Implementation of a priority queue in JavaScript that supports retrieving
elements by priority or by insertion order.

Features:
- insert elements with a priority value
- retrieve highest priority element
- retrieve lowest priority element
- retrieve oldest inserted element (FIFO)
- retrieve newest inserted element (LIFO)

Files:

priorityQueue.js – main implementation  
test.js – simple test cases
